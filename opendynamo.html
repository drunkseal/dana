OpenDynamo: Bit-Exact GPU Spectral-Element Solver

A high-order Flux Reconstruction ($P=3$, 64 solution points/element) solver for 3D compressible Navier–Stokes in a channel box, written in pure Rust with device CUDA kernels synthesized dynamically at runtime via NVRTC. Built for honest, measured performance and bit-for-bit restart exactness.

Asynchronous I/O Dedicated double-buffered background thread with Blosc-LZ4 compressed HDF5 output

1. Mathematical & Numerical Formulation

The solver integrates the three-dimensional compressible Navier–Stokes system written in conservative form for the state vector $\mathbf{U} = [\rho, \rho u, \rho v, \rho w, \rho E]^T$:

∂U/∂t + ∇ · F_inv(U) = ∇ · F_visc(U, ∇U) + S_body

where the pressure is determined via the calorically perfect gas equation of state:

p = (γ - 1) · [ ρE - 0.5 · ( (ρu)² + (ρv)² + (ρw)² ) / ρ ]

1.1 Flux Reconstruction (FR) Collocation

Within each hexahedral element $\Omega_e$, the continuous solution is represented as tensor-product Lagrange polynomials of degree $P=3$ on the Gauss–Lobatto quadrature points. The continuous flux divergence is assembled by adding the local discontinuous flux derivative to a correction field derived from interface Riemann flux jumps:

∂F/∂x ≈ ∂F_loc/∂x + [ F_interface(x_L) - F_loc(x_L) ] · g'_L(x) + [ F_interface(x_R) - F_loc(x_R) ] · g'_R(x)

Choosing the Huynh correction function $g_{DG}$ recovers standard nodal Discontinuous Galerkin behavior with minimal dissipation and maximal spectral resolution.

1.2 Slip & No-Slip Wall Flux Closures

Textbook mirrored-state Riemann fluxes enforce penetration restrictions as $\mathcal{O}(v_n^2)$, allowing fast schemes to leak wall-normal momentum. OpenDynamo replaces this with a direct linear inviscid wall flux:

F_wall = [ 0, 0, p_wall, 0, 0 ]^T

For viscous turbulent-channel validation, the `wall_treatment = "no-slip"` configuration enforces zero velocity at the wall while keeping the traction present in the face correction. The slot-4 energy flux is set to zero, maintaining an exact adiabatic wall condition ($\partial T / \partial y |_{wall} = 0$).

2. Software Architecture & Runtime CUDA Synthesis

Traditional CUDA solvers require an external `nvcc` build chain, complex CMake scripts, and bulky pre-compiled fatbins that limit precision dispatch flexibility. OpenDynamo inverts this model:

NVRTC JIT Compilation

Device kernels are compiled from string templates at runtime by NVRTC into PTX for the exact compute capability of the host GPU.

Macro Precision Dispatch

State, RHS, stage memory, and compute precision can each be toggled between f32 and f64 in the TOML config without recompiling Rust.

Non-Blocking Async I/O

Full state checkpoints stream asynchronously from device memory to a background thread, using Blosc-LZ4 HDF5 compression.

// OpenDynamo Rust Runtime Architecture // Precision pipeline dispatch via macro instantiation: dispatch_pipeline!( u_real = f32, q_real = f32, rhs_real = f32, compute_real = f32, flux_scheme = "slau2", wall_treatment = "no-slip" );

4. Configuration Reference & Quickstart

OpenDynamo configs are explicit and TOML-based without hidden defaults:

# config.toml (Production Channel DNS) [mesh] nx = 48 ny = 48 nz = 48 lx = 12.566370614359172 ly = 2.0 lz = 6.283185307179586 [physics] y_boundary = "wall" wall_treatment = "no-slip" viscosity_model = "fixed" mu_ref = 1.063e-4 # Re_tau = 180 with body_force below t_ref = 273.15 s_suth = 110.4 body_force = 3.66e-4 initial_state = "output/flow_f32_000000.h5" [solver] n_steps = 4000 dt = 5.0e-4 flux_scheme = "slau2" fast_math = true [io] save_freq = 50 checkpoint_freq = 1000 compression = "blosc-lz4" output_dir = "runs/prod" prefix = "flow" [precision] u_real = "f32" q_real = "f32" rhs_real = "f32" compute_real = "f32"
